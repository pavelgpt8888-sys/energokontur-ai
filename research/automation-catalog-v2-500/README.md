# Каталог v2 — 500 идей автоматизации и AI для электроэнергетики

Дата независимого прохода: 2026-09-29.

Это **второй независимый brainstorm с нуля**, а не продолжение старого списка. Первые 300 идей сформированы без копирования структуры v1; затем после gap-review добавлены ещё 200 идей в областях, которые оказались недопредставлены.

## Как читать
- **1–300** — fresh_300: независимый повторный проход.
- **301–500** — extension_200: расширение после анализа пробелов и текущих технологических направлений.
- implementation_hint — ориентир класса реализации, не ТЗ.
- ai_or_advanced_analytics — грубая маркировка для фильтрации, не утверждение, что AI обязателен.

## Источники направления для gap-review
Актуальные международные драйверы 2026: цифровизация и наблюдаемость распределительных сетей, DLR/DTR, topology optimisation, non-firm connections, demand flexibility, BESS, V2G, AI-enhanced grid analytics, OT/AI governance и новые крупные нагрузки вроде data centres.
