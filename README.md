# ЭнергоКонтур AI

Исследования продуктов и бизнес-направлений для электроэнергетики Беларуси и России.

## Разделы

- [`research/ideas/`](research/ideas/README.md) — технологический радар: оборудование и технологии для сетей, подстанций и накопителей. Для каждой идеи — статус импорта, OEM или локализации.
- [`research/automation-ai/`](research/automation-ai/README.md) — автоматизация и ИИ для энергетики:
  - каталог из 300 идей;
  - исследование болей Беларуси;
  - экономика кандидатов, услуг и студии;
  - математика продукта с учётом размера рынка.

## Как пересчитать экономику

```bash
python3 research/automation-ai/economics_model.py
```

Нужен только Python 3.10 или новее, без сторонних библиотек. Все допущения записаны в начале каждой функции `plan_*` и в словаре `MARKET`.
