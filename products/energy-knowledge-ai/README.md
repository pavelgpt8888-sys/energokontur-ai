# Energy Knowledge AI BY

Демонстрационный и далее промышленный продукт для энергетики Беларуси: защищённый корпоративный AI-ассистент для поиска, анализа и проверки нормативно-технических и внутренних документов.

## Целевой первый показ

- Министерство энергетики Республики Беларусь
- ГПО «Белэнерго»
- далее: РУП «Минскэнерго» и другие энергопредприятия

## Ключевой принцип

LLM (Large Language Model — большая языковая модель) является сменным вычислительным компонентом. Базовую LLM и вычисления можно брать у белорусского провайдера. Продуктовая ценность находится в document pipeline (конвейере обработки документов), hybrid search (гибридном поиске), RAG (генерации с поиском по базе), version graph (графе версий), citations (ссылках на первоисточники), access control (разграничении доступа) и evaluation (проверке качества).

## MVP v0.1

Первая версия намеренно узкая и должна уметь:

1. отвечать на вопрос по энергетической нормативной базе;
2. находить правильный документ;
3. показывать точный первоисточник;
4. определять актуальную/заменённую редакцию;
5. сравнивать две редакции;
6. корректно отказываться от ответа, если подтверждающего источника нет.

## Принцип демо

На встрече не объясняем embeddings, vector DB или модель. Пользователь сам задаёт вопрос → получает краткий ответ → открывает источник → проверяет действующую редакцию.
